# Security policy

Please report a vulnerability privately through GitHub's security advisory interface rather than opening a public issue. Do not include real screenshot files, filenames, folder paths, signing material, notarization credentials, or other personal data in a report.

Timestamp Only's safety boundary is intentionally narrow: it is sandboxed, accepts one user-selected folder, carries no network entitlement, processes only positively marked Apple still screenshots, and performs exclusive same-directory renames. Reports about bypassing any of those boundaries are especially valuable.
